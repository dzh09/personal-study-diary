## 怎么读

1. 打开 [站点首页](https://dzh09.github.io/personal-study-diary/)，按入库日期倒序排列，每一天一组；
2. 顶部按主题切换，进入主题页看「概念 / 方法 / 案例」三段；
3. 首页的**原文标题本身就是外链**，点标题直接跳原刊；卡片页底部也写着原文出处。

## 库的结构

| 目录 | 作用 |
| --- | --- |
| `00 入库索引.md` | 导航页：按入库日期列出每篇原文与它拆出的卡 |
| `01 收件箱/` | 待处理稿，处理完即归档 |
| `02 原始资料/` | 原文存档（**只在本地，不进仓库**） |
| `03 提炼笔记/` | 卡片：`概念 / 方法 / 案例` → 主题 → 小主题 |
| `04 主题索引/` | 每个大主题一张页 |
| `05 我的产出/` | 处理清单、周报之类的产出 |
| `06 系统配置/` | 规范、发布配置、生成脚本 |
| `07 归档/` | 已分类原稿、旧主题页、被合并的旧卡 |

## 关于原文与版权

- 原文全文只保存在本地库的 `02 原始资料`，**不随这个仓库发布**；
- 站点和卡片页只提供**指向原刊的链接**并注明出处，不转载正文；
- 卡片内容是本人阅读后的概括与整理，不是原文摘抄。

## 更新方式

本地每天跑一次入库任务：处理收件箱 → 拆卡 → 一致性体检 → 渲染站点 → 推送到 `gh-pages` 分支。这个仓库由脚本自动维护，页面内容以 `gh-pages` 分支为准。
